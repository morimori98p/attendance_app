# マンモス札幌 部活動ポータル

部員が作ったファイルへのリンクを、みんなで貯めていくための一覧です。
サーバーは要りません。フォルダごと USB で配って、`index.html` を開くだけで動きます。

---

## フォルダの中身

```
mammoth-sapporo-portal/
├─ index.html   ← これを開く（ポータル本体）
├─ data.js      ← みんなの一覧データ（共有されるのはこれ）
├─ README.md    ← このファイル
└─ files/       ← 部員が持ち寄った HTML をここに入れる
    ├─ sample.html
    └─ sample-kiroku.html
```

### ヘッダー画像とアイコン（任意）

このフォルダに次の2つを置くと、自動的に差し替わります。

| ファイル名 | 使われる場所 | 目安のサイズ |
|---|---|---|
| `header-mammoth.png` | ヘッダーの大きな画像 | 横 1600px 前後・横長 |
| `icon-mammoth.png` | 左上のアイコン、ブラウザのタブ | 正方形 128px 前後 |

置かない間は、同じ配色で描いたイラスト（青空・丘・マンモス）が表示されます。
どちらか片方だけ置いてもかまいません。

フォルダ名は解凍後に「マンモス札幌ポータル」など日本語に変えても問題ありません。
ただし **ZIPにまとめて配る時だけは、フォルダ名・ファイル名を半角英数にしてください。**
日本語のままZIPにすると、解凍する人の環境によって文字化けすることがあります。

## 使い方（部員）

1. 自分が作った HTML ファイルを `files` フォルダに入れる
2. `index.html` を開き、右上の **「リンクを追加」** を押す
3. 題名とリンク先（例：`./files/自分の資料.html`）を書いて「記帳する」

登録した内容は、まず**その端末のブラウザにだけ**保存されます。この時点では他の人には見えません。

## 使い方（とりまとめ役）

1. 部員から集めた HTML を `files` フォルダに入れる
2. ポータルで全部登録する
3. 右上の **「書き出し」→「data.js を保存」** を押す
4. 保存された `data.js` を、このフォルダの `data.js` と**差し替える**
5. 「この端末の保存分を消す」を押して、二重表示を防ぐ
6. フォルダごと配る

### 部員が登録したぶんを集める場合

部員に「書き出し」→「本文を写す」でテキストを送ってもらい、
とりまとめ役のポータルで「書き出し」画面のテキスト欄に貼り付けて
**「取り込む」** を押すと合流します（同じ題名・リンク先は重複しません）。

## data.js を手で書き足す

エディタで開いて、`items` に次の形を1つ足すだけです。

```js
{
  "id": "any-unique-id",
  "title": "資料の題名",
  "href": "./files/shiryo.html",
  "category": "成果物・作品",
  "author": "森山",
  "date": "2026-09-05",
  "tags": ["AI", "入門"],
  "desc": "一言でどんなものか"
}
```

- `category` は好きな名前を書けば、そのまま新しい分類として左の「目録」に出ます
- `href` は `https://` で始まる URL も使えます（別タブで開きます）
- `date` から14日以内のものには「新着」の印が付きます

## 覚えておくと便利

- キーボードの `/` で検索欄にすぐ移動できます
- 左の「札」（タグ）や「目録」（分類）をクリックすると絞り込めます
- 各行にマウスを乗せると「直す」「消す」が出ます

## 注意

- `data.js` を差し替えたら、必ず「この端末の保存分を消す」を押してください
- ブラウザの履歴・サイトデータを消すと、書き出していない追加分は失われます。こまめに `data.js` へ書き出してください
