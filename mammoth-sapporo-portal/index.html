マンモス札幌

みんなが作ったもの、ぜんぶここに集まる。

このポータルの使い方
  1. 作った HTML ファイルを、index.html と同じフォルダの files に入れる
  2. 右上「＋ リンクを追加」から、タイトルとファイル名（例：./files/tool.html）を書く
  3. 追加したものは、まずこの端末のブラウザだけに保存されます
  4. みんなに配るときは「書き出し」→「data.js を保存」で、フォルダの data.js と差し替える
  5. 受け取った人は index.html を開くだけ。全員分が見られます

※ data.js を差し替えたあとは「この端末の保存分を消す」を押すと、二重に出ません。

※ ZIP にまとめて配るときは、フォルダ名・ファイル名を半角英数に。日本語名のままだと解凍時に文字化けすることがあります。

※ header-mammoth.png と icon-mammoth.png をこのフォルダに置くと、ヘッダー画像とアイコンがその画像に差し替わります。無い間は下の絵で表示されます。

※ キーボードの / で検索欄に移動できます。

リンクを追加

同じフォルダに置いたファイル名を ./ から書きます。https:// で始まる URL も使えます。
下のタグを押すと出し入れできます。新しいタグは上の欄に直接書いてください。

書き出し・取り込み

いま画面に出ている全件を data.js として書き出します。フォルダの data.js と差し替えれば、次に開いた人にもそのまま見えます。
他の人の data.js の中身をここに貼って「取り込む」を押すと、いまの一覧に合流します（同じタイトル・リンク先は重複しません）。
